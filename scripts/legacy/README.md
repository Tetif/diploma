# Legacy scripts

Old one-off utilities from earlier stages of the thesis (large study, timing tables,
distillation table, microservice-driven investigation). They are kept for reference
and are **not** part of the current pipeline (`run_study.py` → `plot_results.py`).
Results they produced were computed before the audit fixes (see `FIXES.md`) and are not valid.
Run them from the repository root, e.g. `python scripts/legacy/collect_influence_timings_table.py`.
