# Экспорт схем для вставки в документ

Для каждой диаграммы лежат три файла с одним содержимым:

| Файл | Назначение |
|------|------------|
| `*.mmd` | Исходник Mermaid (правки вручную или повторный экспорт) |
| `*.svg` | Вектор: LaTeX (`\includegraphics`), Word «Вставка → Рисунок», масштабирование без потери качества |
| `*.png` | Растр: удобно для Word, если с SVG проблемы с шрифтами |

**Имена:**

1. `01_modules` — модульная структура ПО  
2. `02_microservice` — микросервис  
3. `03_main_pipeline` — этапы обработки данных  
4. `04_experiment_loop` — внутренний цикл эксперимента  

**Повторный экспорт** (из каталога `docs/architecture_diagrams`, нужны Node.js и сеть):

```bash
npx @mermaid-js/mermaid-cli@11 -i 01_modules.mmd -o 01_modules.svg
npx @mermaid-js/mermaid-cli@11 -i 01_modules.mmd -o 01_modules.png -w 2200
```

Ширину `-w` при необходимости увеличьте для более крупного PNG.
