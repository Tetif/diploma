# Анализ эволюции кода Zillow проекта

## Обзор версий

### 1. **zillow_main_old.py** - Базовая версия
**Основные компоненты:**
- Простая нейросеть `SimpleNN` (128→64→32→1)
- Базовая обертка `PyTorchModel`
- Функции загрузки и предобработки данных
- Базовые методы influence (LOO, DataShapley, BetaShapley, DirectInfluence)
- Простая нормализация scores

**Особенности:**
- Минимальная функциональность
- Глобальная переменная `X_val_transformed` для scorer'а
- Базовое извлечение значений из результатов pyDVL

---

### 2. **zillow_main.py** - Улучшенная базовая версия
**Добавлено:**
- Улучшенная обработка данных в `comprehensive_preprocessing`
- Более стабильный scorer (`make_stable_neg_mae`)
- Улучшенная нормализация с использованием рангов (`rankdata`)

**Изменения:**
- Убраны некоторые вспомогательные функции
- Упрощена структура кода

---

### 3. **zillow_main_v1.py** - Версия с отладкой
**Добавлено:**
- Флаг `DEBUG_MODE` для управления отладочным выводом
- Функция `debug_print()` для условного логирования
- Улучшенная обработка ошибок
- Параметр `epochs` в `PyTorchModel.fit()`

**Изменения:**
- Более гибкое управление обучением
- Лучшая диагностика проблем

---

### 4. **zillow_main_v2.py** - Версия с улучшенной нормализацией
**Добавлено:**
- Расширенная нормализация scores с использованием рангов
- Winsorized min-max нормализация как fallback
- Обработка смешанных положительных/отрицательных значений
- Улучшенная диагностика извлечения значений

**Изменения:**
- Более устойчивая нормализация к выбросам
- Лучшая обработка edge cases

---

### 5. **zillow_main_v2_1.py** - Версия с сохранением результатов
**Добавлено:**
- Функции `save_results_pickle()` и `load_results_pickle()` для сохранения/загрузки результатов
- Улучшенная визуализация с трендовыми линиями
- Сохранение лучшей модели (checkpointing) во время обучения

**Изменения:**
- Возможность сохранения и загрузки промежуточных результатов
- Воспроизводимость экспериментов

---

### 6. **zillow_main_logger.py** - Версия с логированием
**Добавлено:**
- Класс `ExperimentLogger` для структурированного логирования
- Автоматическое создание папок экспериментов (дата/время)
- Сохранение конфигурации в JSON
- Сохранение результатов в pickle
- Генерация итогового отчета (`generate_summary`)
- Замер времени выполнения этапов (`start_timing`, `end_timing`)
- Сохранение графиков (`save_plot`)

**Изменения:**
- Полная трассируемость экспериментов
- Структурированное хранение результатов
- Детальная статистика по времени выполнения

---

### 7. **zillow_main_models.py** - Версия с множественными моделями
**Добавлено:**
- Базовый класс `BaseModel` для унификации интерфейса
- Множественные модели:
  - `LightGBMModel`
  - `XGBoostModel`
  - `RandomForestModel`
  - `PyTorchModelWrapper` (обертка для PyTorch)
- Улучшенная архитектура `ImprovedNN` (с BatchNorm)
- Фабрика моделей `create_model()`

**Изменения:**
- Поддержка tree-based моделей
- Единый интерфейс для всех моделей
- Возможность выбора модели через параметры

---

### 8. **zillow_main_experimental.py** - Экспериментальная версия
**Добавлено:**
- Метод `LissaInfluence` вместо `DirectInfluence` (более эффективный для больших моделей)
- Экспериментальные настройки методов influence
- Улучшенная обработка ошибок

**Изменения:**
- Тестирование альтернативных методов influence
- Оптимизация для больших моделей

---

### 9. **zillow_main_distillation.py** - Версия с дистилляцией знаний
**Добавлено:**
- Класс `DistilledModelWrapper` для дистилляции знаний
- Возможность дистилляции tree-based моделей в нейросети
- Параметры дистилляции: `temperature`, `distillation_epochs`
- Методы `student_predict()` для использования студенческой модели

**Особенности:**
- Tree-based модели → нейросеть (для использования influence методов)
- Сохранение производительности учителя
- Возможность применения influence методов к tree-based моделям через дистилляцию

---

### 10. **zillow_main_new_models.py** - Финальная версия с новыми архитектурами
**Добавлено:**
- **FT Transformer архитектура** (`FTTransformerModel`, `SimpleFTTransformer`)
  - Transformer-based модель для табличных данных
  - Attention механизмы
  - Более сложная архитектура для лучшего качества
- Поддержка CatBoost модели
- Расширенные конфигурации моделей
- Улучшенная обработка различных архитектур PyTorch

**Изменения:**
- Современные архитектуры нейросетей
- Поддержка attention механизмов
- Более гибкая конфигурация моделей

---
